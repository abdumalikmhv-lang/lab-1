# Лабораторная работа №1 (Малик): Файлы и каталоги

Решение задания лёгкого уровня: создание заданной структуры каталогов и файлов с помощью системных вызовов UNIX на языке C и через shell-скрипт. Структура выдаётся преподавателем на занятии, поэтому при необходимости имена, размеры и расположение нужно изменить под полученный вариант.

## Структура из примера

```text
a/
├── b/
│   └── cat.txt        ("catts")
├── c/
│   └── dog.txt        (пустой)
├── d                  (символьная ссылка на c)
└── e/
    ├── f.txt          (жёсткая ссылка на ../b/cat.txt)
    ├── g.bin          (500 байт, случайные данные из /dev/urandom)
    └── h.bin          (35 байт, заполненные нулями)
```

## Запуск

В терминале перейдите в папку с файлами.
Для программы на C:

```sh
gcc -Wall -Wextra -std=c11 -o lab1_malik lab1_malik.c
./lab1_malik
ls -liR a
```

Для `sh`-скрипта (перед запуском можно очистить старую папку `rm -rf a`):

```sh
chmod u+x lab1_malik.sh
./lab1_malik.sh
ls -liR a
```

Оба способа создают одинаковую структуру и размеры; случайные данные из `/dev/urandom` при каждом запуске различаются. Программа и скрипт останавливаются с ошибкой, если целевой каталог или файл уже существуют (например, при повторном запуске без удаления `a/`).

## Как объяснить

* `mkdir` создаёт каталоги с заданными правами доступа (`S_IRWXU`). `open` создаёт или открывает файлы и возвращает их дескрипторы; `write` записывает текст и данные, `close` закрывает дескрипторы файлов.
* `read` читает случайные байты из `/dev/urandom`; `ftruncate` устанавливает размер файла (при увеличении пустого файла до 35 байт дополняет его нулями).
* Жёсткая ссылка (`link`) — ещё одно имя тех же данных: у двух имён (`a/b/cat.txt` и `a/e/f.txt`) общий `inode`. Символьная ссылка (`symlink`, `a/d`) хранит путь (`c`) к целевому каталогу или файлу.
